# Lucid Tarkov

Download the latest launcher from the [Releases](https://github.com/Shurtug/Lucid/releases/latest) page.

## Features

### Aimbot
- Silent aimbot with adjustable target size/color and on-screen target indicator ("Magic Bullet" mode)

### Visuals
- **ESP** — players, NPCs, extracts, transits and active quest objectives, each with its own color, plus adjustable font size
- **Chams** — separate player/gear/weapon chams with visible & invisible colors, scope/arms toggles
- **Radar** — top-down radar window with NPC/PMC/quest marker colors, adjustable size and range
- **Vision** — thermal vision with selectable color palette and adjustable saturation, no-visor mode

### Minimap
- In-raid minimap overlay — satellite or abstract style, adjustable size/zoom/opacity/position, rotates with player, shows players/bots, extracts and quest markers

### Loot ESP
- Full loot ESP with price-tier coloring (common/rare/superrare), quest item highlighting, min-value and wishlist filtering, high-penetration ammo and high-class armor highlighting
- Crosshair hover focus with adjustable radius, distance-based detail scaling
- One-click dump of the nearest container or all nearby items for inspection

### Player
- God Mode, Infinite Stamina, No Hunger/Thirst
- Instant Search, Always Survive
- Speed Hack with adjustable speed, Fly/Noclip
- Add EXP / Fence Reputation / Trader Reputation, adjustable skill levels
- Spoof Nickname

### Weapon
- No Malfunction (disables jams/misfires/overheating), Infinite Ammo
- Instant Magazine Load/Unload

### Item Spawner
- Spawn any item by name (searchable dropdown), including quest items and transit items
- Found-in-Raid toggle, custom stack amount, target slot override
- No slot restrictions, increased stack/transfer sizes
- Restore key uses / medkit HP / fuel-resource charges on use
- Resize your backpack (custom width/height)

### AI Spawner
- Spawn any AI type on demand — scavs, PMC BEAR/USEC, raiders, rogues, cultists, infected, and every named boss (Reshala, Killa, Shturman, Gluhar, Sanitar, Tagilla, Knight, Zryachiy, Kaban, Kolontay, Partisan, Wedge)
- Adjustable difficulty and spawn count
- "Spawn At My Position" — spawns near you and teleports the bot to your exact position
- "TP Spawned To Me" — teleport any newly spawned bot to your location

### Quests
- List all quests with live status (available, started, completed, failed)
- Accept, complete, or fail/reset any quest, or complete individual conditions by ID

### World
- Unlock all doors
- Teleport nearby AI to your position

### Misc
- Custom watermark (text, color, font size)
- Built-in web dashboard — control settings remotely from a browser
- Debug mode for troubleshooting

## Support
